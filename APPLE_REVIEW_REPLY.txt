For version 1.0.82 (92), we revised the app as follows.

Guideline 1.1.6:
- RefurbX no longer presents device memory or storage integrity as a diagnostic. The former memory test was removed. A separate informational screen displays volume capacity values returned by public Foundation APIs; the occupied value is an estimate. These values do not create a test result, are not saved or transmitted, and are excluded from diagnostic reports and exports.
- The light test follows a user-observed iOS auto-brightness check. It displays the screen brightness level and asks the operator to enable Auto-Brightness and observe the display while changing ambient light. The displayed percentage is the screen brightness, not a direct reading of the ambient-light sensor or a lux measurement. The result is confirmed by the operator.
- The NFC explanation screen has no Skip option. Continue starts the Core NFC reader session directly and displays Apple's system scanning sheet.
- The app's home screen contains a link to its privacy policy.

Guideline 5.1.1(iv):
- Explanations for features requiring camera, microphone, location, and other system authorization proceed to the relevant system flow without a Skip button before the permission request. Users can decline in Apple's prompt; denied permissions are not reported as hardware failures.
- The light test does not request camera access.
- Settings links use Apple's public app-settings URL. When iOS does not provide a direct settings destination for a radio, the app shows instructions with Retry and Skip controls.
- The compass test reads magnetic heading directly and does not request location access; only the GPS test uses location permission.
- Sending diagnostic information to a workstation requires an explicit user action.

The app provides guided functional checks using public APIs and operator observations. It does not certify complete hardware integrity. TrueDepth and ARKit data used during their respective checks are processed temporarily on device and are not included in exports.

Thank you for reviewing the updated submission.
