Thank you for the detailed feedback regarding submission 133894b8-df2a-4885-9f1d-b74f6347c8cb, version 1.0.80 (82).

We have revised the project for version 1.0.82 (90) as follows:

Guideline 1.1.6:
- The app does not offer a device memory diagnostic. The old diagnostic implementation and memory-test state have been removed. A separate informational screen displays total and available volume capacity returned by public Foundation APIs; occupied space is estimated. It does not test RAM or storage hardware integrity, has no pass/fail result and is excluded from diagnostic reports and shop exports. These display-only values are not persisted or sent off-device. The privacy manifest declares disk-space reason 85F4.1.
- The light check shows a relative 0–100 index derived from front-camera exposure while the user covers and illuminates the front upper area. The app explains that this is a camera-based exposure indicator, not lux and not direct access to the ambient-light sensor. Frames are processed in memory, not saved or sent. The operator confirms only an observed change; no change is inconclusive, not a hardware diagnosis.
- The NFC explanation screen has a Continue button without a Skip option. Tapping Continue starts the Core NFC reader session directly, which displays Apple's system scanning sheet. A separate retry button is available only if the session ends before a tag is read.
- The public privacy-policy link is visible on the app's home screen before starting tests.

Guideline 5.1.1(iv):
- The custom explanations preceding permission-related features do not include a Skip button. Continue starts the relevant feature and its system authorization flow when authorization has not already been determined.
- Users can decline the system permission. Camera, microphone and location denial are handled without reporting the missing permission as a hardware defect, and the user can skip the unavailable test.
- Links for changing app permissions now use Apple's public app-settings URL.
- Preparing the cable outbox requires the user to select Send to workstation. Previous outboxes are removed when starting the app or a new session.

The app provides guided functional checks using supported APIs and explicitly identified operator observations. It does not certify complete hardware integrity. No account is required for the on-device checks. Sending the report to a shop workstation is optional.

For TrueDepth, ARKit face mesh and the camera preview are used temporarily during the test. The app does not access Face ID biometric templates or an infrared image, and the preview and mesh are not included in the exported report.

Thank you for reviewing the updated submission.
